# NEXUS OMEGA Clean Chat Final

This package contains a clean working FastAPI app with:

- `/chat` page with visible prompt box
- loading/progress indicator
- `/api/chat`
- `/api/browser`
- `/api/research`
- `/api/product-team`
- `/api/artifacts`
- markdown + JSON artifact generation
- Playwright browser extraction
- light/dark mode

## Deploy from Mac

```bash
unzip nexus_omega_clean_chat_final.zip
cd nexus_omega_clean_export
bash deploy_from_mac.sh
```
